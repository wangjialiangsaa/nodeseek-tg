NodeSeek 登录状态

在 nodeseek.com 登录后，从浏览器开发者工具复制请求凭据。

如何获取 Cookie 和 User-Agent？
  1. 打开 nodeseek.com，完成登录和验证。
  2. 按 F12 → Network（网络），刷新私信页面。
  3. 找到 notification/message/list 请求，在 Request Headers 中复制 Cookie 和 User-Agent 的值。
  4. 填写个人主页 /space/ 后的数字 ID，保存后测试论坛连接。

服务器若遇到验证，可能需要在同一出口 IP 下登录。Cookie 过期后需重新导入；程序不会保存论坛密码。
